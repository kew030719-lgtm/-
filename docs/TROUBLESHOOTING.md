# 故障排查

## Chrome 助手未连接

打开 `/api/browser-helper/status` 查看 `connected` 和 `last_seen_at`。超过 75 秒未收到心跳会显示断开。确认主程序正在运行、扩展已启用、扩展地址为 `http://127.0.0.1:8000`。助手只接受 localhost HTTP 地址。

## 验证码或登录

任务应进入 `NEEDS_MANUAL_INPUT` 并保留队列位置。请在专用采集标签页手动完成验证，再点扩展“继续任务”。系统不绕过验证码。

## 错误密钥或模型超时

在首次启动向导重新填写服务地址、模型名和密钥，并执行“保存并测试”。失败响应不会回显原始密钥。没有可用模型时，能确定性完成的能力会明确标为本地降级；需要模型且无法安全降级的任务会失败。

## 页面结构变化

采集指标的 `failure_category` 为 `page_structure` 时，先保存页面脱敏样本并补回归 fixture，再修改站点适配器。禁止把列表页、导航或推荐职位误存为岗位职责。

## 应用重启

后端会把中断的非聊天任务恢复为可重试状态；Chrome 助手在本地存储中保存任务阶段、队列、标签页、上次/下次导航时间，可从原位置恢复。
